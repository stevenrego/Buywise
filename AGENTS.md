# BuyWise Kuwait

- This is a Kuwait-first product comparison app inspired by Flash-style shopping flows.
- The primary user path is search, paste, or share a product, then compare prices across Kuwait stores first.
- Wider comparison scopes are Middle East and worldwide.
- Keep the visible experience comparison-first. Verdict-style output is secondary.
- Do not add wallet, cashback, payment, loyalty, or CAF-related features.
- Never commit real secrets. Use `.env.local` for local values and `.env.example` for placeholders.
- Before deploying, verify `npm run lint`, `npm run typecheck`, and the `/compare` route behavior.
